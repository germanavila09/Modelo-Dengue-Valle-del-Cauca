① App — reemplaza Runner
google.adk.apps.app.App
▼
💡Patrón oficial de ADK que habilita compactación, caché de contexto y memoria en una sola instancia. Con Runner básico ninguna de estas funciones está disponible.
adk_app = App(
  name = "observatorio_geosalud",
  root_agent = root_agent,
  session_service = InMemorySessionService(),
  artifact_service = InMemoryArtifactService(),
  events_compaction_config = EventsCompactionConfig(...),
  context_cache_config = ContextCacheConfig(...),
  memory_service = InMemoryMemoryService(),
)
🗜️
② EventsCompactionConfig
google.adk.apps.app.EventsCompactionConfig
▼
token_threshold = 16 000 event_retention_size = 4 compaction_interval = 15 overlap_size = 2
💡Comprime automáticamente el historial cuando supera 16 000 tokens. Conserva siempre los últimos 4 eventos sin comprimir para mantener coherencia.
Impacto en sesión larga:
Sin compactar → ~40k tokens/turno → Compactado → ~8k tokens/turno
⚡
③ ContextCacheConfig
google.adk.agents.context_cache_config.ContextCacheConfig
▼
min_tokens = 2 048 ttl_seconds = 600 cache_intervals = 10
💡Cachea los system prompts estáticos con Gemini 2.0+. Los prompts del orquestador y subagentes superan 3k tokens — se envían una vez y se referencian por hash en los siguientes 600 s.
Los prompts no cambian entre turnos → cada turno ahorra el costo de procesar ~3-5k tokens de instrucciones repetidas.

④ InMemoryMemoryService + preload_memory

⑤ ParallelAgent — epidemio_viz_parallel✦ NUEVO
google.adk.agents.parallel_agent.ParallelAgent
▼
💡Ejecuta epidemio_agent y viz_agent en paralelo cuando el usuario pide datos y gráfica en el mismo mensaje. Sin dependencias entre ramas → ambos procesan simultáneamente.
epidemio_viz_parallel = ParallelAgent(
  name = "epidemio_viz_parallel",
  description = "Usame cuando el usuario
    pida datos Y gráfica en el mismo turno.",
  sub_agents = [epidemio_agent, viz_agent],
)
Triggers: "dame el top y la gráfica" · "serie en tabla y gráfico" · "visualiza y muéstrame los números"

📊 Consulta numérica → epidemio_agent
"¿Cuántos casos de dengue tuvo Cali en 2024?"
🧠 Orchestrator analiza la intención del mensaje intent: consulta numérica → epidemio_agent
🧠 preload_memory carga preferencias de la sesión anterior memoria recuperada: "usuario prefiere incidencia"
🔧 epidemio_agent ejecuta la herramienta SQL casos_por_municipio_anio("CALI", 2024)
📤 PostgreSQL/PostGIS retorna el dato → 4.823 casos · incidencia 183.4/100k hab.
✅ Cali 2024: 4.823 casos · Incidencia 183.4/100k · Responde en incidencia por preferencia recordada de sesión anterior, sin que el usuario lo repita.
📈 Solicitud visual → viz_agent
"Dame la gráfica del top 5 de municipios en 2024"
🧠 Orchestrator detecta solicitud de imagen/gráfica intent: visual PNG → viz_agent
🔧 viz_agent llama la herramienta de visualización grafica_top_municipios(anio=2024, n=5)
🗂️ Caché determinista — verifica si el artifact ya existe artifact "top5_casos_2024.png" → ¡ya existe!
📤 Reutiliza el PNG sin volver a generarlo → PNG desde InMemoryArtifactService · 0 ms matplotlib
✅ Gráfica PNG: top 5 municipios 2024 reutilizada desde caché · 0 ms de procesamiento matplotlib · Artifact devuelto al frontend.
🗺️ Control de UI → ui_agent
"Abre el mapa de incidencia de 2024 sin incluir Cali"
🧠 Orchestrator detecta acción de interfaz intent: navegación UI → ui_agent
🔧 ui_agent ejecuta la herramienta de mapa mostrar_mapa_coropletico(var="incidencia_dengue", anio=2024, incluir_cali=False)
📡 Retorna JSON action al frontend (sin esperar LLM) {"type":"map","var":"incidencia_dengue","anio":2024,"incluir_cali":false}
🌍 Frontend actualiza Leaflet.js sin recargar → coroplético renderizado con geom PostGIS (41 municipios)
✅ Mapa actualizado: incidencia 2024 · 41 municipios (sin Cali) · JSON action via capa local FastAPI · Leaflet.js renderiza en tiempo real.
