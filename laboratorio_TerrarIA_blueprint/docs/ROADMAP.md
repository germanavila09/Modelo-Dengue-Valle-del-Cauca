# Roadmap - Laboratorio TerrarIA

## Fase 1 - Fundacion

- Crear estructura matriz `laboratorio_TerrarIA`.
- Registrar GeoSalud como primer observatorio.
- Crear GeoTurismo con arquitectura reciclada.
- Definir plantilla comun de README, docs, scripts y outputs.
- Publicar landing estatica del laboratorio.

## Fase 2 - GeoTurismo MVP

- Definir fuentes de datos turisticas.
- Crear modelo de datos territorial.
- Construir indicadores basicos.
- Generar primer mapa interactivo.
- Crear tablero HTML inicial.

## Fase 3 - Componentes comunes

- Extraer utilidades compartidas a un paquete `terrarIA_core`.
- Estandarizar estilos de graficas y mapas.
- Crear validadores de calidad de datos.
- Crear plantillas de presentacion y reportes.

## Fase 4 - Portafolio de observatorios

- Integrar GeoCiudad, GeoAmbiente, GeoRiesgo y GeoMovilidad.
- Crear catalogo de proyectos y aliados.
- Preparar demostraciones por linea estrategica.
