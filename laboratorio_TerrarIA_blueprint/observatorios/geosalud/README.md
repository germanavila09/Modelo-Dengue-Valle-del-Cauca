# GeoSalud

GeoSalud es el observatorio avanzado de salud publica del Laboratorio TerrarIA.

El desarrollo operativo se encuentra actualmente en:

```text
E:\observatorio_geosalud
```

## Proposito

Analizar territorialmente eventos de salud publica mediante datos espaciales, indicadores, mapas, modelos predictivos y tableros interactivos.

## Capacidades ya avanzadas

- Conexion PostgreSQL/PostGIS.
- Limpieza y transformacion de datos epidemiologicos.
- Indicadores municipales.
- Priorizacion territorial.
- Graficas descriptivas.
- Mapas interactivos.
- Modelos predictivos.
- Frontend y chatbot territorial.

## Rol dentro de TerrarIA

GeoSalud funciona como observatorio piloto para definir la arquitectura replicable del laboratorio.
